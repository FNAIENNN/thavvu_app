================================================================================
                    THAVVU APP - MODULE & DATA INPUTS ANALYSIS
================================================================================
This file compiles a detailed analysis of all data entry modules, user screens, 
input types, data structures, and forms present in the Thavvu App codebase.
It serves as the foundation for building the Reports Page.

--------------------------------------------------------------------------------
MODULE 1: LOGIN & SESSION MANAGEMENT
--------------------------------------------------------------------------------
File: lib/screens/login_screen.dart
Purpose: Secure access for supervisor or other roles (HOD, Admin) and session establishment.

User Input Elements:
1. Email / Username Field
   - Widget Type: TextFormField
   - Controller: _emailController
   - Input Type: text / email address
   - Validation: Required, must be a valid email format.
2. Password Field
   - Widget Type: TextFormField
   - Controller: _passwordController
   - Input Type: text (obscured by default, toggleable visibility)
   - Validation: Required, character length checks.
3. Remember Me Checkbox
   - Widget Type: Checkbox
   - Variable: _rememberMe (boolean state)
   - Input Type: Boolean toggle (Checked/Unchecked)

Submission Logic:
- Button: Login (ElevatedButton)
- Target: FormState validation. Upon success, calls AuthService.login(email, role) 
  which persists session variables (is_logged_in, user_name, user_email, user_role, emp_id) 
  to SharedPreferences.

MODULE 2: WORKERS & ATTENDANCE
--------------------------------------------------------------------------------
File: lib/screens/attendance_screen.dart & lib/screens/food_screen.dart
Purpose: Tracking regular/outside workers, wages, advances, and shift-based food counts.

User Input Elements:
A. Daily Attendance Checklist (Regular Workers)
   - Widget Type: Toggles / Gesture Detectors
   - Input Type: Selection status per worker ('Present', 'Absent', 'Half day', 'Leave')
   - Target Variable: Attendance status list map

B. New Worker Enrollment
   - Widget Type: TextFields inside bottom sheet / form
   - Fields:
     * Full Name (fullNameController) - Text
     * Aadhar Number (aadharController) - Number string (12 digits)
     * Referral Name (referralController) - Text
     * Joining Date - DatePicker
   - Attachments:
     * Bank Book Photo - Camera/Gallery file picker
     * Aadhar Photo - Camera/Gallery file picker
     * Profile Photo - Camera/Gallery file picker
   - Biometric Setup:
     * Register Face Template - Callback triggers face extraction/storage
     * Register Bio Template - Callback triggers fingerprint scanner simulation

C. Outside Labor Attendance (Supplier & Batch Wise)
   - Widget Type: TextFields & Dropdowns inside BottomSheet
   - Fields:
     * Supplier Selection - Dropdown list of labor suppliers OR
     * Custom Supplier Name (_customSupplierController) - Text input (activated by switch)
     * Custom Supplier Toggle - Switch (boolean)
     * Worker Count (_countController) - Number input
     * Wages per Shift (_wageControllers mapping) - Text/Number inputs:
       - Morning Shift Wage (Default 300)
       - Afternoon Shift Wage (Default 300)
       - Full Day Shift Wage (Default 600)
       - Others Shift Wage (Default 500)
     * Batch Type / Shift - Selection dropdown (Morning, Afternoon, Full Day, Others)
     * Custom Bill/Invoice Number (customBillController) - Text input
     * Attachments: Bill Photo (tempBillPhotoPath) - Camera file capture

D. Permanent Worker Payments & Advances Tab
   - Widget Type: Search field & bottom sheet forms
   - Search Field: Search permanent workers (_paymentSearchController) - Text input
   - Add Used/Advance Amount Form:
     * Used Amount (usedAmountController) - Number input
     * Note / Description (noteController) - Text input (Default: 'Advance/used amount before salary')
     * Transaction Mode - Selection (UPI, Bank transfer)
   - Salary Payout Sheet:
     * Cash Amount (_cashAmountController) - Number input
     * Request Pay / Advance Amount (_advanceAmountController) - Number input
     * IFSC Code (_ifscController) - Text input (Auto-fills on saved accounts)
     * Account Number (_accNumController) - Number input (Auto-fills on saved accounts)
     * Bank Name (_bankNameController) - Text input (Auto-fills on saved accounts)
   - Adjust/Edit Cash Payment Dialog:
     * Correct Cash Amount (editController / retrievedController) - Number input
   - Saved Account Management (UPI & Bank):
     * Add UPI: UPI ID (upiController) [Text], Account Name (bankController) [Text]
     * Add Bank: Bank Name (bankNameController) [Text], Account Number (accountController) [Text], 
       IFSC Code (ifscController) [Text], Holder Name (holderController) [Text]

E. Food Management (lib/screens/food_screen.dart)
   - Widget Type: Multi-select tags, Toggles, and TextFields
   - Fields:
     * Select Shifts for Food - Multi-select Tags (Morning, Afternoon, Evening)
     * Food Attendance Checklist:
       - Regular Workers - Toggles (Yes / No)
       - Outside Workers - Toggles (Yes / No)
       - Machine Workers - Toggles (Yes / No)
     * Add Guests:
       - Guest Name (_guestNameController) - Text input
       - Guest Count (_guestCountController) - Number input
     * Add Others:
       - Item/Event Name (_otherNameController) - Text input
       - Plate Count (_otherCountController) - Number input

C. Daily Data Machine Allocation & Time Blocks (lib/screens/daily_data_screen.dart)
   - Widget Type: TextFields & TimePickers
   - Fields:
     * Machine Search - search machine by ID, type, location (_machineSearchController) - Text
     * History Search - search log history (_historySearchController) - Text
     * Add Time Block:
       - Start Time - TimePicker dialog
       - End Time - TimePicker dialog
       - Destination / Remarks - Text
       - Thavvu ID (Auto-selected or Text)
       - Notes (_notesController) - Text
     * Cash Payout Enable - SwitchListTile
     * Cash Payout Amount (_cashAmountController / amountController) - Number
     * Request Pay / Advance Amount (_advanceAmountController) - Number
     * Manual Bank Details for Payout:
       - Holder Name (holderController) - Text
       - Account Number (_accNumController / accNumController) - Number
       - Bank Name (_bankNameController / bankNameController) - Text
       - IFSC Code (_ifscController / ifscController) - Alphanumeric
       - UPI ID (upiController) - Text
     * Retrieve/Return Fuel:
       - Litres retrieved (retrievedController) - Number input
     * Beta Management:
       - Regular Beta Amount (_betaController) - Number input
       - Enable Extra Beta - SwitchListTile
       - Extra Beta Amount (_extraBetaController) - Number input
       - Extra Beta Reason / HOD Note (_extraBetaNoteController) - Text input

D. HOD Machine Verification & Payments (lib/screens/machines_entry_screen_.dart)
   - Widget Type: TextFields, Switches, and Sliders
   - Fields:
     * Operator Name (_operatorNameController) - Text
     * Machine ID (_machineIdController) - Text
     * Total Amount (_amountController) - Number
     * Used Amount (_usedAmountController) - Number
     * Advance Amount (_advanceAmountController) - Number
     * Used Advance Amount (_usedAdvanceAmountController) - Number
     * Additional HOD Notes (_notesController) - Text

MODULE 6: CASH & PAYMENTS
--------------------------------------------------------------------------------
File: lib/screens/cash_screen.dart
Purpose: Managing supervisor cash-on-hand expenditures, advances, and transport split bills.

User Input Elements:
A. Cash Payout Log (Petty Cash Expenses)
   - Widget Type: TextFields & Dropdowns
   - Fields:
     * Cash Amount (_amountController) - Number input
     * Remarks (_remarkController) - Text input
     * Expense Category - Dropdown selection (e.g., food, transport, salary, assets, others)
     * Thavvu ID (_selectedThavvuId) - Dropdown selection of site IDs
     * Asset Details (enabled only for 'assets' category):
       - Item Name (_itemNameController) - Text
       - Quantity (_itemQuantityController) - Number
       - Price per Item (_itemAmountController) - Number
     * Invoice Attachment - File path picker (temp path)

B. Transport Split Bill Form
   - Widget Type: TextFields, Checkboxes & Splits
   - Fields:
     * Total Transport Amount (_transportTotalController) - Number
     * Split Mode - Toggle button selection (Equal Split vs Manual Split)
     * Split Amounts Map (_splitAmounts mapping) - Number inputs (visible in Manual mode)
     * Transport Remarks (_transportRemarkController) - Text
     * Split Recipients - CheckboxListTile per supervisor/worker
     * Attachments:
       - Vehicle Photo (transportVehiclePhotoPath) - Camera file capture
       - Invoice/Bill (transportInvoiceBillPath) - Camera file capture

C. Request Pay (Request cash advance from office)
   - Widget Type: TextFields, Uploads & Audio recording
   - Fields:
     * Request Amount (_requestAmountController) - Number
     * Reason / Purpose (_requestReasonController) - Text
     * Payment Method - Selection (UPI vs Bank Transfer)
     * UPI ID (_upiIdController) - Text (only visible for UPI mode)
     * Manual Bank Details (only visible for Bank mode):
       - Bank Holder Name (_bankHolderNameController) - Text
       - Account Number (_bankAccountNoController) - Number
       - Bank Name / IFSC Code (_bankIfscCodeController) - Text / Alphanumeric
     * Audio Note - Recording triggers voice file path
     * Photo upload - Image file path selection
     * Bill/Invoice upload - Image file path selection

D. Contra Entry (Direct cash transfer between supervisors)
   - Widget Type: Dropdown & TextField
   - Fields:
     * Recipient Supervisor ID (_contraSelectedToId) - Dropdown selection
     * Contra Amount (_contraAmountController) - Number input
